<td width="100%">

**🚗 Distracted Driver Detection & Explainable AI System**
`PyTorch` `ResNet50` `GradCAM` `OpenCV` `Streamlit`

End-to-end computer vision system trained on 22,424 labelled images across 10 distraction categories. Uses transfer learning on ResNet50 with class-weighted loss, and GradCAM heatmaps to verify predictions focus on driver hands and devices — not background noise. Deployed as a real-time Streamlit app with confidence-threshold safety alerting.

**🩺 Diabetes Risk Stratification & Preventive Care Advisor**
`Scikit-learn` `Random Forest` `SHAP` `KMeans` `KNN` `Streamlit`

Four-stage pipeline — Clustering → Classification → Explainability → Recommendation — built on ~100,000 patient records. Random Forest classifier reached **F1 0.804 / ROC-AUC 0.837**. Per-patient SHAP explainability paired with a KNN-based recommendation engine surfacing personalized lifestyle targets.
